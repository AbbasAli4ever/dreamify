# UI icons

Thin line icons for buttons and navigation, in the same style as the symbol icons.

- 24×24 `viewBox`, `fill="none"`, **white** stroke (`stroke="#FFFFFF"`), stroke width 1.5, round caps and joins.
- Recolor in code with a `stroke` prop (e.g. ink on white buttons).
- Imported as React components through `react-native-svg-transformer`.
