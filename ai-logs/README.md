# AI Session Logs

Every AI-assisted session used to build this project is logged here as a Markdown file, containing the prompts sent and the AI's responses.

## How logs are produced

- **Claude Code:** at the end of each session, run `/export` and save the output into this folder.
- **Other tools:** use the tool's export or share feature, or copy the conversation into a `.md` file.

## Naming

`YYYY-MM-DD-NN-short-topic.md`, where `NN` is the session number for that day, for example `2026-09-27-01-project-setup.md`.
